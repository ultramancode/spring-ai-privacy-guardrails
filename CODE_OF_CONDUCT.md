# Code Of Conduct

This project follows the [Spring Code of Conduct](https://github.com/spring-projects/.github/blob/main/CODE_OF_CONDUCT.md).

Be respectful, constructive, and welcoming in issues, reviews, discussions,
and all other project spaces. Harassment, discrimination, threats, and the
publication of another person's private information are not acceptable.

Report conduct concerns privately to the maintainer at
[ktw2172@gmail.com](mailto:ktw2172@gmail.com).
